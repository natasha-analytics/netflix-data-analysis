# Netflix Data Analysis 📊

This project explores Netflix movies and TV shows using data analytics techniques.

## Dataset
The dataset contains information about:
- Movies and TV Shows available on Netflix
- Genre, country, release year
- Ratings and duration

## Objectives
- Analyze content distribution (Movies vs TV Shows)
- Find most common genres on Netflix
- Analyze trends over years
- Country-wise content availability

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook (Google Colab)
